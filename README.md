# Lesehelfer

Liest Texte aus Spielen, vom Desktop und in VR laut vor (Windows 10/11).

- **Spiele:** Textfeld markieren, neue Texte werden vorgelesen (auch PS2-Emulator PCSX2).
- **Desktop:** Mit der Maus auf einen Text zeigen und eine Taste drücken.
- **VR:** Mit SteamVR auf einen Text schauen und die Controller-Taste drücken.
- Englische Texte können offline ins Deutsche übersetzt werden.

Das fertige Komplettpaket (mit eingebautem Python) gibt es als ZIP vom Entwickler.
Der Lesehelfer holt sich Updates von dieser Seite automatisch.
